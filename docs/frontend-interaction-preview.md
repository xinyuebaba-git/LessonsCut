# 前端交互预览

访问 `/preview.html`。原入口 `/` 保持现有应用行为。本轮仅做交互确认，没有接入新的后端接口。

## 交互范围

- 新建批次：多选/拖入视频，展示名称与大小，追加/移除/清空；确认批次名称、片头和三个模型后，一次创建演示批次。仅读取浏览器文件元数据，不上传或分析。
- 处理任务：阶段推进、分类、异常分支、标题确认后恢复；全部为内存演示数据。没有真实成片或伪造下载。
- 模型配置：三个角色分别修改服务商、地址、模型 ID、密钥、超时与限额。检查按钮仅做格式检查，明确未联网；保存只在本次预览内存中生效，清空密钥字段。不使用真实配置或浏览器持久化存储。
- 剪辑模板：公共片头素材入口、1.5 秒逐课标题、无风格时的模板策略、收束语定格策略。
- 登录：侧栏「查看登录页」进入；演示密码不发往服务器，提交后清空。正式版将复用现有服务端管理认证。

## 视觉依据与边界

沿用现有 LessonsCut 字标、主色 `#176450`、浅灰工作区。面向桌面批量制作，减少营销内容，以清单、阶段、证据和角色配置为主。没有另造学校 logo，也未读取视频画面。标题页仅作排版示意，标记为非生图结果。

待用户确认交互后，再实现配置持久化、凭据管理、配置快照、能力验证、真实批量上传和启动。监督仍用 MiniMax、视频分析仍用现有 3090 Qwen、生图仍用阿里 Qwen-Image；预览中自定义服务只展示选择行为，不代表已支持任意模型协议。

构建：`cd frontend && npm run build`。Vite 多入口同时产出正式入口和独立预览，不修改 API/Worker 或历史任务。

- TypeScript 检查与 Vite 双入口构建通过；`git diff --check` 通过。
