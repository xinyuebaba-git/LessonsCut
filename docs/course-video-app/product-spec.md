# 产品规格 v1.0

## 目标与已确认范围

将一批课程视频按一致规则处理为“统一片头＋精简标题页＋连续授课”，减少人工逐条识别和导出工作，并留下可解释、可修正的依据。主要使用者为课程制作负责人和审核人员；首版以单机构、单管理员工作流设计，不引入多租户、计费平台或公共分享。

交付成片、可重建工程、生成资产、复核报告和模型用量。首版提供表单式切点/标题修正，不开发轨道拖拽编辑器，不增加字幕、去 logo、配音、背景音乐或授课内部精剪。素材本身已有字幕和声音保留。

默认业务规则见 [识别与剪辑规则](../../skills/course-video-batch-edit/references/workflow.md)，验收规则见 [检查与验收](../../skills/course-video-batch-edit/references/verification.md)。

## 默认模板

| 项目 | 首版默认 | 批次可覆盖 |
|---|---|---|
| 片头 | 广州开放大学已批准参考资产，6s | 资产、匹配规则、时长 |
| 标题 | 课名＋有证据的讲师，1.5s，沿原风格生成 | 时长、文字、批准风格 |
| 授课 | 首次正式出镜讲解至授课结束，连续保留 | 人工修订首尾并附理由 |
| 视频 | 1920×1080、H.264、yuv420p、等比留边 | 首版只允许帧率策略与质量配置调整 |
| 帧率 | 已确认源标称帧率，输出 CFR | 指定有理数帧率 |
| 音频 | AAC 48kHz，保留 mono/stereo，授课原声 | 首版不允许变速/配音；多声道转人工确认 |
| 标题音频 | 经证据确认的可用原音乐，否则静音 | 人工批准的源区间或静音 |
| 生图 | 云端，独立配置 | 本地受控生图服务 |
| 审批 | 确定任务自动，异常人工 | 可选择整批计划确认 |
| 输出 | 配置目录，新文件，保留版本 | 可选已授权可写的原片目录 |

1.5s 为目标值；25fps 实际为 38 帧/1.52s，页面同时显示目标与实际。片头也执行同样量化。新任务不能继承先前任务的讲师、标题或切点。

## 用户流程与页面

**配置页**：注册本地识别、云端监督、生图三个角色；绑定凭据引用、能力、限额、模型生命周期管理权限；登记片头与素材/输出根目录。提供连接测试和能力验证，未通过的配置不可用于自动批次。配置变更只作用新修订，运行中任务保持快照。

**新建批次**：浏览器上传到隔离入库目录，或选择服务器授权目录下文件；没有目录输入就默认上传。显示素材数、时长、估算空间、模板、三类模型、外发内容和预算上限；一次提交授权本批执行。预算为管理员设定的必填任务限额，费用无法估计的角色需显式选择“仅限制调用量/耗时”。

**批次列表**：每条显示文件、阶段、等待原因、已用资源与结果。显示阶段进度；没有测得速度时不编造总体 ETA。单条失败不阻塞其他视频，可单条取消/重试，批次取消只影响尚未发布的工作。

**任务详情与修正**：三段式输出预览、源/输出双时间显示；课名与姓名附证据；起止点旁显示邻帧和本地音频试听；标题页显示版本与复核问题。用户可改标题、讲师、起止点或选定生成页，保存形成新修订，确认预览后重新处理。

**异常箱**：呈现问题、实际证据、影响和可执行选择。标题推断必须确认；姓名完全无证据可省略，模糊有证据则待核实；切点冲突必须选择/修正并说明依据。技术解码失败或缺文件不能通过人工“忽略”变成可交付。

**交付页**：下载 MP4、工程包、报告。显示实际规格、抽样范围、人工例外、源哈希、审核版本和用量。工程包包含 manifest、源文件哈希/相对引用、生成图和参数；默认不重复打包大源视频，因此跨服务器重建需提供同哈希源素材。

## 自动处理与人工边界

自动条件为证据完整、必需校验通过、模型间无未解决冲突、模板允许、预算充足。自报置信度仅决定追加采样，不单独决定通过。

异常包括缺少批准片头、口头标题无音频能力、推断标题、无法辨认的姓名、授课与片尾音画交叠、VFR 输出率不明确、源中含多个独立课程、HDR/隔行/多声道未支持、服务失败、预算或磁盘不足、质量返工超限。多课程文件首版不自动拆课，进入人工选择单课或排除。

模型网络重试总尝试最多 3 次；任务自动质量返工最多 2 轮，不按子阶段反复清零。人工恢复可建立新修订但保留历史总次数和费用。无人处理的异常不应反复自动调用模型。

## 成功指标与限制

必须保证原片不被覆盖、连续授课范围正确、标题准确、实际输出可解码、审核与交付哈希一致。记录每小时素材的人工介入数、返工率、推理/渲染耗时、GPU 峰值显存、每分钟输入成本及未知用量比例，用压测建立目标值；不预先承诺并发数、吞吐或准确率。

服务器只需出站访问指定云模型服务；首版在内网访问，管理员认证必需。生产服务、模型权重选择、驱动安装和网络开放属于后续实施，不在本次交付执行。
