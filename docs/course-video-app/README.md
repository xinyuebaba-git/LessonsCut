版本：1.0，2026-10-15。状态：**技能包与开发设计已编写；应用尚未实现、部署或压测**。

翔哥确认的边界：单张专用 24GB RTX 4090；本地内容识别、云端监督评估、独立可配置生图模型；服务器独立剪辑并提供修正入口；正常任务自动执行、异常人工处理；首版只做基础剪辑。

## 技能使用与分发

技能包位于项目 `skills/course-video-batch-edit/`，入口是 SKILL.md，元数据是 agents/openai.yaml；全部规则参考均在包内，可单独分发。当前只保存项目副本，未修改全局技能目录或注册宿主应用。支持本地技能目录的宿主可将整个目录加入其技能发现路径；注册后通过 `$course-video-batch-edit` 调用。未注册时可明确要求智能体读取项目内 SKILL.md。

应用设计文档不作为技能运行的必要依赖。配置中的 null 表示尚未部署的必填现场绑定，不是可直接运行的默认服务地址。真正执行前必须登记模型、片头资产、预算和媒体目录并完成能力验证。

## 与历史成果的关系

1、3 号成片与原始记录仅作为只读证据，本次未重新剪辑或识别。历史成功不等于未来应用已经通过验收。历史 3 号含新增字幕，首版应用不负责再生成这些字幕；重建时应使用基础内容预期而非要求成片逐像素一致。

规则以技能参考文档为唯一详细来源，设计文档引用这些规则；实例值不得反向覆盖业务配置。后续开发应先实现最小竖向流程，再按验收案例扩展，不将历史一次性脚本直接改地址后作为生产服务。
