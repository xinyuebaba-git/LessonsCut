# 批量制作工作台接入记录 · 2026-10-16

用户确认交互原型后，将登录、新建批次、任务列表、模型配置与剪辑模板接入真实 API。`/preview.html` 保留为独立模拟入口；正式入口为 `/`。

## 使用流程

1. 用服务器 `LESSONSCUT_ADMIN_TOKEN` 对应的「访问密码」登录。该值与任何模型 API Key 无关。
2. 在模型配置页分别指定视频分析、监督评估和标题生图服务。当前实现支持 OpenAI 兼容多模态识别、MiniMax / OpenAI 兼容监督、DashScope 原生生图。自定义服务必须兼容所选协议，不代表任意模型都已适配。
3. 剪辑模板选择已批准的广州开放大学片头；保存时检查文件哈希、视频流和至少 6 秒可用时长。学校身份继续由任务模型识别与复核。
4. 一次多选或拖入课程视频，或从已入库视频选择；启动前可追加、移除、清空。此时只读浏览器元数据，不上传、不创建任务。
5. 确认批次名称、片头、模型版本与云端外发范围后，点击「开始批量处理」。先顺序入库，再一次性创建整批任务。每批最多 100 课，单文件最多 20 GiB；片头不加入课程任务。
6. 正常课程逐条自动识别课名、生成各自的 1.5 秒标题页并复核。没有原片标题风格时，可用配置的统一模板；标题推断、姓名不确定或证据冲突仍交人工。
7. 任务页按批次和状态查看；异常抽屉提供课名、讲师、切点、定格原声终点、源证据、转写和调用记录。人工图片放在折叠备用入口，默认仍自动生图。

## 配置与凭据

- `.env` 提供首次引导和部署配置；现有数据库首次启动时生成配置 v1，之后通过页面保存不可变版本。再次编辑 `.env` 不会静默覆盖已经保存的三个模型角色。
- 每个批次保存 `config_version`、`batch_name`。识别、渲染、失败重试和人工新修订继续使用该版本；明确点击「按当前配置重新分析」才绑定最新配置。保存配置采用版本比较，冲突返回 409。
- 凭据保存在被 Git 忽略的 `data_dir/credentials/`，目录 0700、文件 0600；版本表只保存不可变文件引用。它们是受文件权限保护的明文凭据，并非 KMS 加密存储；服务器备份与磁盘访问仍需按凭据管理。
- GET 配置只返回是否已配置，绝不回显密钥或凭据引用。新密钥写入独立文件，旧版本继续引用旧凭据。更换地址时必须明确重新填写或清除密钥，防止旧密钥被意外发给新地址。
- 角色请求超时、角色调用上限和每课总调用上限均生效，失败请求计入用量；图片尝试与 token 分开记录。图片生成仍最多初稿加两轮修正，实际还受累计预算约束。
- 本地 ASR 的 SSH/CPU 部署配置与 GPU 服务生命周期不在此页面修改。当前仍用现有 3090 Qwen 服务，应用不会安装或切换服务器模型。

## 登录与提交保护

- 登录成功建立 8 小时、HttpOnly、SameSite=Strict 的随机会话 Cookie，数据库仅存会话摘要；HTTPS 时设置 Secure。退出即撤销会话。保留原 Bearer API 认证兼容脚本。
- Cookie 写请求检查同源 Origin 和专用请求头；密码接口限制每个连接来源每分钟 10 次尝试。前端不在 localStorage/sessionStorage 保存密码或模型密钥。
- 上传失败时复用本批已成功入库的素材。批次提交超时或 5xx 结果不明确时，锁定本次提交参数，使用同一幂等标识重试；明确的 4xx 拒绝允许修正后重新确认。
- 配置测试只在保存后执行：识别/监督发送合成红色块验证图片输入和 JSON 返回，可能消耗 token，并记录调用；生图配置检查不创建付费图片，也不宣称已联网验收生图能力。
