# 识别与剪辑规则

## 证据优先级

每个事实携带素材哈希、源 PTS/时间基准、样本引用、模型版本和调用编号。区分“直接读取”“口头明确说明”“人工确认”“模型概括”；模型自报高置信度不能代替证据。

片头必须匹配配置的学校名称、视觉身份和完整性。相同文件或已登记片段哈希可机械确认，其余由识别模型对照批准的参考片头。相符且可完整保留指定时长才保留，否则使用登记片头资产；没有资产则待人工配置。片头资产携带自身音频，不将原视频被删除开场的音轨叠加进去。

标题选择顺序：原片中明确的本节课标题 → 授课课件标题或讲师明确口头说明 → 人工确认的概括标题。系列/栏目标题不能取代具体课名。不同直接证据冲突时提交冲突及对应时间，不按排列顺序机械择一。标题中仅保留具体课名；“第六课”等编号默认去除，除非批次模板另有要求。

讲师姓名仅来自明确署名、自我介绍或人工确认。没有任何姓名证据时省略，不猜测；有模糊姓名或多个不明角色时转人工。原文字保留书写形式，简繁转换等文字改动需要在模板中明确。

口头说明需本地音频识别能力与带时间戳的转写证据。模型只有图片能力时，另接配置的本地语音识别适配器；它属于识别环节，不引入新的监督角色。图片不能证明说了什么。关键人名和课名出现转写冲突时转人工。

## 抽样与边界精查

初始策略（配置默认，不是验收充分性的证明）：头尾各 60 秒按 2 秒采样，其他部分按 30 秒采样；短片重叠区间去重。场景变化、黑场或静音可作为追加取样的机械线索，不直接判定语义。

每批图片保留独立 ID、源 PTS、顺序与清晰文字；按模型输入限制分批，不强行塞入低清接触表。检查模型是否漏样本、重复样本、编造不存在的时间。边界候选两侧扩展上下文，再按 0.5 秒、逐帧层级精查。只有单一且经确认的状态变化区间可收窄；非单调、多个转场或类别修订必须扩大区间重新判断。

授课起点：主讲人首次进入本次课程讲解的画面，包含相关自我介绍；片头中的人物预告不算。若课程本来没有人物出镜，或画外正式讲解先于人物出现，则转人工确认起点例外，不能丢弃已确认的有效教学。

授课终点：相关授课与收束语完成、进入片尾之前。致谢是否属于讲师收束语，需结合画面和音频判断；不得将首次出现的非人物画面当作结束。连续保留起止之间的课件、演示、空镜与画外讲解，不自动消除停顿。

如果教学语音已叠在片尾或边界处存在未完句，不能同时满足“连续原声”和“删片尾”时转人工处理，禁止静默截断。没有足够音频证据的可疑边界不得自动通过。

## 标题生成

发给生图模型的输入包含：批准的精确文字、无新增文字要求、原风格参考或本地模型提取的配色/构图/字体风格说明、16:9 画幅、关键文字安全区。不将“还原原标题风格”理解为复制制作单位、系列或 logo。

每版结果保存生成请求、供应商任务 ID、原始图片、资产哈希、费用和复核结论。监督模型先提取生成图实际文字，再与批准文本比较；检查漏字、错字、额外文字、边缘裁切及风格。首版风格失败应修改针对性约束，不悄悄改课名。

图片分辨率和画布分辨率分别记录。默认等比适配画布；只有边缘安全区确认无损时可做轻微 cover 裁切，否则等比留边或重新生成。最终验收针对合成视频的标题首、中、末帧，不仅检查 PNG。

## 时间与声音

源区间统一为 `[start_pts, end_pts)`，使用每条流的有理数 time_base；整数 frame index 只用于有明确映射的 CFR。VFR 读取实际解码帧 PTS，不能用 frame/fps 反推时间。非零起始 PTS 和音视频起始偏移必须保留到映射中。

输出默认 CFR，沿用经探测确认的源标称帧率。缺少可信标称帧率的 VFR 素材转人工选择输出率；不能悄悄当作 30fps。输出帧数采用有理数计算、四舍五入且半帧向上：`round_half_up(duration × fps)`。25fps 的 1.5 秒为 38 帧即 1.52 秒；30fps 为 45 帧。逐段记录目标时长、实际时长与误差，累计输出位置由整数帧数求和。

授课音频不变速、不降噪、不配音。画面做 VFR→CFR 映射时保持时间，不以帧索引强行拉伸音轨。精确切点通常需解码重新编码，不能无条件 stream copy 到非关键帧；“保留原声”不等于压缩数据逐字节相同。

标题音频：只有证据确认原相应区间是完整可用的配乐/无语音音轨时才取指定长度；无证据或会截断口播时默认静音，不增加新音乐。音频策略写入计划。最后一段因输出帧量化产生的极短时长差，用末帧保持/尾部静音对齐，禁止截去实际教学语音；超过量化允许范围转人工。

默认 1920×1080、方形像素、H.264、AAC；等比缩放并留边，不裁切教学信息。首版自动处理 SDR；HDR、复杂色彩转换、隔行素材先转人工，避免自动造成严重色差或梳齿。这些例外不代表原素材已经损坏。
